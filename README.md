
# Clinician Patient Management
  
AirAware, a new wave AI based medical assistant. Logging into AirAware for the first time you receive a quick questionnaire to fill out. The questionnaire scouts out COPD including its risk factors, like smoking, and possible symptoms like frequent cough, wheezing, sleep disruptions, prolonged colds and frequent hospitalizations. If the person is already diagnosed with COPD, the AirAware opens up a personalized view for them where they can fill in their personal treatment plans with the assistance of a health care professional. It will track their passive health signals to create a personalized baseline and when combined with environmental data from the internet (pollen, pollution ect.), it calculates a real-time personal risk score for an COPD exacerbation to happen. Based on the risk score AirAware will trigger automatic personalized care pathways to stop exacerbations at their first signs.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
